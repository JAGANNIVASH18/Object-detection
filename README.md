# Real-Time Object Detection Using YOLOv4

## Aim

To perform real-time object detection using a trained YOLOv4 model through the laptop webcam.

---

## Objective

The objective of this experiment is to detect and recognize multiple objects in real-time using the YOLOv4 (You Only Look Once Version 4) deep learning model and display the detected objects with bounding boxes and labels through a webcam feed.

---

## Software Requirements

- Python 3.x
- OpenCV
- NumPy
- Matplotlib
- Jupyter Notebook / Anaconda

---

## Files Required

1. yolov4.cfg
2. yolov4.weights
3. coco.names
